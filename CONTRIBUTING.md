# Contributing to PhrasePatch

Thanks for helping build PhrasePatch.

## Development

```bash
npm install
npm run check
```

## Pull requests

Keep pull requests focused and explain the user-facing behavior being changed. New coaching behavior should preserve PhrasePatch's core rule: language feedback must not alter the meaning of the user's actual request.

## Commit style

Conventional Commits are encouraged:

```text
feat: add language auto-detection
fix: avoid repeated coaching after tool calls
docs: add Spanish configuration example
```
